One word, first thought: "coffee". The program writes it to
`/output/entry.txt`; an AI judge pairs words head to head and crowns the one
that feels most like a first thought.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
